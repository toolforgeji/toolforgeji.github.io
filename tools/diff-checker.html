About the Text & Code Diff Checker

Compare two blocks of text or code side by side. Additions and deletions are highlighted line by line, with synchronized line numbers and counters. Use it to review changes between drafts, configuration files, or code versions without sending them to a server.

How to use it

  1. Paste the original text in the left pane.
  2. Paste the revised text in the right pane.
  3. Review additions (+) and deletions (-).

How to use the Diff Checker

  1. Paste the original version into the left pane.
  2. Paste the revised version into the right pane.
  3. Read the output: green lines are additions (+) and red lines are deletions (-), with line numbers on both sides.
  4. Click Copy Diff to share the result, or use Swap Panes to reverse the comparison.

Use Load Sample to see how the tool works before you paste your own text.

Frequently Asked Questions

Is my text sent to a server?

No. The comparison runs in your browser, so drafts, configuration files, and code stay on your device.

Can I compare code and JSON?

Yes. The diff works on any plain text, including source code, JSON, YAML, and configuration files.

What do the colors mean?

Green marks lines added in the revised version, and red marks lines removed from the original.
