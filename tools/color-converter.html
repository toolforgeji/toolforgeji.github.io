How It Works

01. Select or Input

Use the color wheel, click a preset, or type any valid 3 or 6-digit hex code.

02. Format Sync

Mathematical formulas calculate normalized RGB, HSL angles, and CMYK percentages synchronously.

03. WCAG Testing

Relative luminance equations calculate WCAG AA (4.5:1) and AAA (7:1) contrast scores for design systems.

About the Color Converter Studio

Convert colors between HEX, RGB, HSL, HSV, CMYK, and OKLCH, and check WCAG contrast ratios for text and backgrounds. Generate tint and shade palettes and copy values with one click. Useful for designers and developers checking accessibility.

How to use it

  1. Enter a color in any format.
  2. Copy the equivalent values.
  3. Check the contrast ratio. WCAG AA requires at least 4.5:1 for normal-size text.
