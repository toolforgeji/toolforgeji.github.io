Frequently Asked Questions

Can I reorder PDF files before merging?
Yes, you can use the Up and Down arrow buttons next to each file to change their merge order.
How does the page range syntax work for splitting?
You can enter single pages (e.g., "1, 4, 7") or hyphenated spans (e.g., "2-6"). Spaces are ignored.
Can I merge password-protected PDFs?
Due to browser security sandboxes, password-protected encrypted PDFs must have their security removed before merging.
