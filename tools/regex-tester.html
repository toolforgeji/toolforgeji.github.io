Frequently Asked Questions

Which regular expression engine is used?
The tester uses your browser's native ECMAScript RegExp engine, fully supporting lookaheads, lookbehinds, unicode properties, and named capture groups.
What do flags g, i, m, and s do?
g: Global search (finds all matches rather than stopping at the first).
i: Case-insensitive matching.
m: Multiline mode (^ and $ match start and end of each line).
s: DotAll mode (. matches newline characters).
Can I test capture group replacements?
Yes, in the Substitution section, use $1 for Group 1, $2 for Group 2, etc., to preview output replacements.
