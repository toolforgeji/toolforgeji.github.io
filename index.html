Frequently Asked Questions

Clear answers to common questions regarding privacy, security, and usage.

Are my files or text ever sent to a remote server?
No. ToolForge uses client-side Web APIs, HTML5 Canvas, Web Workers, and WebAssembly to run all operations entirely in your browser memory. You can inspect the network tab in your browser's developer tools to verify that zero file bytes leave your computer.
Is ToolForge free for commercial use?
Yes. You are free to use ToolForge for personal, educational, or commercial projects. Invoices, generated QR codes, optimized graphics, and code formatting can all be utilized for business operations without attribution.
How does ToolForge make money if it's free with no ads?
Because all processing happens on the client side, our server hosting costs are negligible (it is just static file delivery). ToolForge is maintained as an open-source public service for developers and creators.
Can I run ToolForge completely offline?
Yes. Once you load a tool page, the client script is cached in your browser. You can disconnect from Wi-Fi or go into airplane mode and continue formatting JSON, testing regex, calculating loans, and generating QR codes.
